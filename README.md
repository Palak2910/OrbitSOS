# OrbitSOS – Satellite Mission Control & Failure Simulator

OrbitSOS is an interactive web-based simulator for monitoring simulated satellite telemetry and exploring different orbital failure scenarios.

## Features
- Animated Earth and satellite orbit visualization
- Simulated satellite altitude, velocity, and orbit telemetry
- Power failure simulation
- Overheating simulation
- Communication signal loss simulation
- Attitude drift simulation
- Dynamic system alerts and reset controls

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Use the failure buttons to explore the different simulated scenarios.
4. Click the reset control to restore normal readings.

**Note:** All telemetry and failure scenarios are simulated. This project does not connect to real satellites.
